# ePortfolio — электронное портфолио достижений

Веб-система для учёта и демонстрации достижений студентов и преподавателей
образовательной организации: олимпиады, конкурсы, конференции, публикации,
сертификаты, повышение квалификации. Достижения подтверждаются файлами и
проходят проверку куратором, после чего попадают в публичное портфолио.

## Возможности

- личный кабинет студента и преподавателя;
- добавление достижения с категорией, уровнем (колледж, город, регион, Россия,
  международный), датой и подтверждающим документом (PDF, JPG, PNG);
- проверка и подтверждение достижений куратором группы или методистом;
- публичная страница портфолио по ссылке с настройкой видимости;
- рейтинг студентов группы по баллам за подтверждённые достижения;
- выгрузка портфолио в PDF;
- роли: студент, преподаватель, куратор, администратор;
- отчёты для учебной части: достижения по группам, отделениям и периодам.

## Технологический стек

| Слой | Технология |
|------|------------|
| Язык (сервер) | Python 3.12 |
| Фреймворк API | FastAPI, Pydantic 2 |
| ORM и миграции | SQLAlchemy 2, Alembic |
| СУБД | PostgreSQL 16 |
| Хранилище файлов | MinIO (S3-совместимое) |
| Клиентская часть | Vue 3, Vite, Pinia, Vue Router |
| Кеш и очереди | Redis |
| Инфраструктура | Docker, Docker Compose, GitHub Actions |
| Качество кода | Ruff, pytest, ESLint, Prettier |

## Развёртывание

1. Клонировать репозиторий:
   `git clone https://github.com/<логин>/eportfolio.git && cd eportfolio`
2. Создать файл окружения: `cp .env.example .env` и заполнить значения.
3. Запустить контейнеры: `docker compose up -d --build`
4. Применить миграции: `docker compose exec api alembic upgrade head`
5. Создать администратора: `docker compose exec api python -m app.cli create-admin`
6. Открыть http://localhost:5173 (клиент) и http://localhost:8000/docs (API)

## Правила работы с репозиторием

- основная ветка `main` защищена, прямые коммиты запрещены;
- разработка ведётся в ветках `feature/<задача>`, `fix/<задача>`, `docs/<задача>`;
- сообщения коммитов по соглашению Conventional Commits (`feat:`, `fix:`, `docs:`);
- слияние только через Pull Request с одобрением ревьюера и успешным CI.
